NPU 地址空间分配规则

1. 初始化数据按 build 合并顺序从0x00000000连续放置：
   image -> weight -> bias -> instr

2. 运行时输出数据从0x00200000开始连续紧密放置，不考虑内存复用，用完就废弃

eg：初始化数据区：
   image : 0x00000000 - 0x0003FFFF, size 0x00040000
   weight: 0x00040000 - 0x0004008F, size 0x00000090
   bias  : 0x00040090 - 0x0008008F, size 0x00040000
   instr : 0x00080090 - 0x000800CF, size 0x00000040

那么，运行时输出区：
   conv_output      : 0x00200000 - 0x00240000, size 0x00040000
   bias_add_output  : 0x00240000 - 0x00280000, size 0x00040000

说明：
   conv_output 的起始地址 = 0x00200000
   bias_add_output 的起始地址 = conv_output_start + conv_output_size = 0x00240000
   当前一层输出按 256 * 256 * 4 byte 计算，大小为 0x00040000。
