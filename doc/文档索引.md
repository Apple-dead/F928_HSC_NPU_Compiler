# 文档索引

本文档用于帮助维护者快速理解当前 NPU 编译器工程。

建议阅读顺序：

1. `编译器整体运行流程说明.md`
   - 了解从 `model.pt2` 到 `data/model_ir.json`、`data/model_params/`、`data/memory_plan.json`、指令和最终 COE 的主流程。
2. `generate_model_ir说明.md`
   - 了解 PT2 前端如何读取 `torch.export` 模型、生成标准 IR、导出标准参数文件。
3. `当前能力与限制.md`
   - 快速确认当前模型输入、支持算子、通道能力、stride/padding、无 bias 行为、`INFER_PARSE_OP_LIMIT` 和 `CONV_MOVE_BY_INDEX` 规则。
4. `generate_memory_plan说明.md`
   - 了解 `data/model_ir.json -> data/memory_plan.json` 的字段和地址规划规则，尤其是 `conv_index`。
5. `NPU_特性与数据排列规则.md`
   - 了解 image、weight、bias、runtime feature map 的物理布局约定。
6. `generate_instr说明.md`
   - 了解如何从 `memory_plan.json` 和 `intr_move.json` 生成 `data/instr.asm` / `data/instr.txt`。
7. `operator说明.md`
   - 了解 `operator/` 下各算子如何把 op plan 编译成汇编片段。
8. `assembler说明.md`
   - 了解汇编指令如何编码成 32-bit 机器码。
9. `回归测试说明.md`
   - 了解 `test/basic` 通用不变量测试、`test/modelX` golden fixture 回归测试的目录约定和执行流程。
10. `NPU指令手册.md`
   - 指令编码和寄存器字段参考。

当前核心数据流：

```text
model.pt2
  -> python/generate_model_ir.py
  -> data/model_ir.json
  -> data/model_params/layerN_0_weight.txt
  -> data/model_params/linearN_weight.txt

data/model_ir.json
  -> python/generate_memory_plan.py
  -> data/memory_plan.json

data/memory_plan.json + intr_move.json
  -> python/generate_instr.py
  -> data/instr.asm
  -> data/instr.txt

data/model_params + data/memory_plan.json
  -> python/params_to_bram_coe.py
  -> coe/layerN_params.coe

data/instr.txt
  -> python/instr_txt_to_bram_coe.py
  -> coe/instr.coe

IMAGE_PATH 指向的输入 COE + coe/layerN_params.coe + coe/instr.coe + data/memory_plan.json
  -> python/merge.py
  -> target/all.coe
  -> target/all.coe.map.txt
```

当前最重要的事实：

- 编译器模型输入统一为 `MODEL_FORMAT = "pt2"` 和 `MODEL_PATH`。
- 旧的模型定义 AST 解析和 `.pth` 参数提取入口已经不再属于主流程。
- `data/model_ir.json` 是前端和后端之间的标准中间层。
- `INFER_PARSE_OP_LIMIT` 按有效 IR op 计数，量化辅助节点不计入。
- memory plan 会为每个参与编译的 conv 写入 `conv_index`。
- `intr_move.json` 由 `INTR_MOVE_PATH` 指定，并用 `CONV_MOVE_BY_INDEX` 按当前 IR 中第 N 次 conv 配置 move。
- 当前前端可以表达 `conv2d`、`relu`、`avgpool2d`、`maxpool2d`、`linear`；`flatten` 作为透传节点忽略。
- 当前后端支持 `conv2d/relu/avgpool2d/maxpool2d/linear` 路径；`linear` 会展开为多条 FULL 指令。
- 无 bias 的 `Conv2d` 不生成 bias 文件，不分配 bias 区，不写 padded bias，RCONV `condition_bias` bit 为 0。
